# Fix CI failure caused by Python 3.8 unavailability on Ubuntu runner

The CI test suite failed during the `setup-python` step on GitHub Actions:
```
The version '3.8' with architecture 'x64' was not found for Ubuntu 26.04.
The list of all available versions can be found here: https://raw.githubusercontent.com/actions/python-versions/main/versions-manifest.json
```

### Cause
- Python 3.8 reached End of Life (EOL) in October 2024.
- GitHub Actions runners using `runs-on: ubuntu-latest` updated to newer Ubuntu environments where precompiled Python 3.8 binaries are no longer built or listed in the `actions/python-versions` manifest.
- When `actions/setup-python@v5` attempts to set up Python 3.8 on `ubuntu-latest`, it cannot resolve the binary, failing the entire job matrix.

### Proposed Fix
- Bump the project's minimum supported version 2–3 versions down from 3.16:
  - **Python 3.13 (3 down)** *(Recommended minimum)*: Supported by modern runners and current test suite, while cutting off older EOL/legacy versions (3.8–3.12).
  - **Account for the newest GitHub-supported versions (3.14 & dev)**:
    - Include `3.14` in the test matrix.
    - Set `allow-prereleases: true` in `actions/setup-python@v5` so that pre-releases and release candidates of upcoming versions can resolve cleanly.
    - Optionally add upcoming versions (e.g. `3.15-dev`) using `include:` with `continue-on-error: true` for early warning without blocking CI.
- In `.github/workflows/ci.yml`:
  - Update matrix to `python-version: ["3.13", "3.14"]`.
  - Add `allow-prereleases: true` to the `actions/setup-python` step.
- In `README.md`, update the Python badge to `python-3.13+`.
- Update [tickets/T5.md](tickets/T5.md) to record the minimum version decision (Python 3.13+).
