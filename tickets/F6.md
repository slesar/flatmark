# Installer trust: pinned versions, checksums, pipx/uvx

The one-liner pipes an unpinned `main` branch into Python. Many teams will not allow that, and a
bad push to `main` breaks every new install immediately.

Acceptance criteria:
- [ ] Installer supports `FLATMARK_REF` (tag/commit); README one-liner uses a pinned release tag.
- [ ] Release artifacts include SHA256 checksums; installer verifies them when available.
- [ ] Evaluate publishing to PyPI so `pipx run flatmark install` / `uvx flatmark install`
      works (extra distribution and discovery channel).
- [ ] README documents the safer install options.
