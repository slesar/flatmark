# Ticket linting command

A `lint` / `check` command that validates all tickets so agents can self-correct.

Checks:
- Missing or invalid frontmatter
- Missing `id`, or `id` ≠ filename
- Unknown `status` / `priority` values
- Duplicate IDs (B9)
- Parent/blocker references to non-existent tickets
- Parent cycles (B1)
- `Done`/`Obsolete` tickets still in `tickets/`, or active tickets in `archive/`

Acceptance criteria:
- [ ] `flatmark.py lint` reports issues as `file:line: message` and exits 1 on errors.
- [ ] `--fix` for safe auto-fixes (e.g. move `Done` tickets to `archive/`).
- [ ] Mentioned in `AGENTS.md` as a mandatory step before committing.
