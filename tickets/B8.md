# board.py exits 0 on errors and prints errors to stdout

When `tickets/` is missing, `board.py` prints an error to stdout and exits with code 0. CI jobs,
git hooks and AI agents rely on exit codes to detect failures.

Acceptance criteria:
- [ ] All error messages in `board.py`, `new.py`, `install.py` go to stderr.
- [ ] Failures exit with a non-zero code (e.g. 1 for errors, 2 for usage errors).
- [ ] `new.py` propagates board update failures.
- [ ] Tests assert exit codes via subprocess.
