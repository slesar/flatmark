# Duplicate ticket IDs silently overwrite each other

`board.py` stores tickets in a dict keyed by `id`. Two files with the same `id` (e.g. after
merging two branches that both created `T5`, or a copy-pasted ticket) result in one of them
being silently dropped, depending on `os.listdir` order.

Acceptance criteria:
- [ ] Duplicate IDs are detected and both files are listed in a stderr warning.
- [ ] Both tickets still appear on the board (e.g. keyed by filename internally).
- [ ] A mismatch between `id` and filename produces a warning.
- [ ] Regression test.

Related: F1 (preventing collisions in the first place).
