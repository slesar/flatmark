# Improve AGENTS.md: schema, workflow, discoverability

The installed `flatmark/AGENTS.md` is the primary interface for AI agents. It should be strict,
complete and easy to discover.

Acceptance criteria:
- [ ] Frontmatter **schema table**: field, required, allowed values, default
      (`id`, `priority`, `status`, `parent`, `blocked by`).
- [ ] Explicit **agent workflow checklist**: pick ticket → set `In Progress` → implement →
      verify acceptance criteria → set `Done` + move to `archive/` → run `board.py` → commit with
      `[#ID]`.
- [ ] Discoverability: most agents read the project-root `AGENTS.md` / `CLAUDE.md`, not
      `flatmark/AGENTS.md`. Installer offers (or documents) adding a one-line pointer to the
      root agent file.
- [ ] Customization story: upgrades overwrite `AGENTS.md`; support/document an
      `AGENTS.local.md` for project-specific rules that is never overwritten.
