# Parent cycles and self-parent drop tickets from board

`board.py` only renders tickets reachable from "roots" (tickets with no parent or an unknown
parent). If tickets form a cycle (`T1 -> T2 -> T1`) or a ticket references itself
(`parent: T3`), none of them is a root and they are **silently omitted** from `BOARD.md`.

Agents treat `BOARD.md` as the source of truth, so a missing ticket is effectively lost.

Location: `board.py` root detection and `traverse()`.

Acceptance criteria:
- [ ] Every ticket in `tickets/` appears on the board exactly once.
- [ ] Self-parent and cyclic parents are detected; affected tickets are rendered as roots.
- [ ] A warning naming the offending ticket IDs is printed to stderr.
- [ ] `traverse()` is guarded against infinite recursion (visited set).
- [ ] Regression tests for self-parent and 2+ node cycles.
