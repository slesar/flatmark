# Quoted YAML values keep their quotes

The ad-hoc frontmatter parser keeps surrounding quotes, so `status: "Todo"` renders as
`⏳ "Todo"`. AI agents frequently quote YAML values. Inline comments (`priority: P1 # urgent`)
are also kept verbatim.

Acceptance criteria:
- [ ] Matching single/double quotes around values are stripped.
- [ ] Inline ` # comment` suffixes on unquoted values are ignored.
- [ ] Supported YAML subset is documented (flat `key: value`, quotes, comments, comma lists).
- [ ] Regression tests.
