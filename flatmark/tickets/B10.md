# new.py may overwrite an existing ticket file

`new.py` writes the new ticket with `open(path, "w")`. If the computed file already exists
(race between two agents, case-insensitive filesystems, manually created file), it is
overwritten without warning.

Acceptance criteria:
- [ ] Ticket file is created with exclusive mode (`"x"`).
- [ ] On `FileExistsError`, retry with the next ID or fail with a clear error and non-zero exit.
- [ ] Regression test.
