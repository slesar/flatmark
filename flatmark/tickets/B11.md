# install.py silently creates non-existent target directory

`python3 install.py /path/to/my-projcet` (typo) creates the whole directory tree and installs
FlatMark there without warning, because `os.makedirs(..., exist_ok=True)` is called on the
destination.

Acceptance criteria:
- [ ] If the target project root does not exist, the installer fails with a clear error and
      non-zero exit.
- [ ] Optional `--create` flag (or confirmation prompt) to allow creating it explicitly.
- [ ] Regression test.
