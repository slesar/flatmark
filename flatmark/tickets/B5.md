# Blocker links break when blocker is archived

Blocker links are always generated as `tickets/<ID>.md`. Once the blocking ticket is completed
and moved to `archive/`, the link 404s. The link also assumes the filename equals the ID.

Acceptance criteria:
- [ ] Blocker links resolve to the actual file location (`tickets/` or `archive/`).
- [ ] Blockers that do not exist anywhere are rendered as plain text and produce a stderr
      warning.
- [ ] Regression tests for active, archived and missing blockers.

Visual marking of resolved blockers is tracked separately in F5.
