# Agent workflow for archive compression and architectural decisions ledger

As projects mature, `flatmark/archive/` accumulates dozens or hundreds of files. While individual ticket files create filesystem and search noise for AI agents and human developers, their underlying architectural decisions, rationale, and tradeoffs remain valuable historical context.

Since Git history already permanently preserves every ticket commit and diff, we can "compress" long history by having agents distill key decisions and changes into a consolidated, high-density ledger (`flatmark/DECISIONS.md`) and prune older ticket files from the working tree.

### Proposed Workflow & Convention
1. **Decision Ledger (`flatmark/DECISIONS.md`)**:
   A lightweight markdown file capturing architectural decisions and milestones extracted from completed tickets:
   - Ticket ID & Title (e.g., `[#F1] Short random hash ID scheme`)
   - Context / Problem
   - Chosen Decision & Tradeoffs
   - Commit / Date
2. **Agent Guidance in `AGENTS.md`**:
   Add a dedicated section to `AGENTS.md` guiding agents on:
   - When to trigger history compression (e.g. archive file count threshold or end of a milestone).
   - How to extract decisions into `DECISIONS.md` without losing critical rationale.
   - How to prune the archived ticket files using `git rm` (or safe removal).
   - How to retrieve archived ticket details from git history when needed (`git log -S`, `git show`).

Acceptance criteria:
- [ ] Document the "History Compression & Decision Ledger" workflow in `src/flatmark/AGENTS.md` and sync to `flatmark/AGENTS.md`.
- [ ] Define the recommended schema and formatting for `flatmark/DECISIONS.md` with concrete examples.
- [ ] Provide explicit agent step-by-step instructions for extracting decisions, updating `DECISIONS.md`, and safely pruning archived files.
- [ ] Document how developers and agents can inspect pruned tickets via Git history (`git log --all -- "flatmark/archive/<ID>.md"`).
- [ ] Verify `flatmark.py lint` and `board.py` pass cleanly with pruned tickets.
