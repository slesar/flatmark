# Multiple blockers produce a broken link

`blocked by: T1, T2` is rendered as a single link `[T1, T2](tickets/T1, T2.md)`, which is
broken. Real tickets often have more than one blocker.

Acceptance criteria:
- [x] `blocked by` accepts a comma-separated list of IDs.
- [x] Each blocker is rendered as its own link, separated by `, `.
- [x] Supported syntax is documented in `AGENTS.md` and `README.md`.
- [x] Regression test with 1, 2 and 3 blockers.
