# Refactor core scripts to modern Python practices

Group of code-quality improvements for `board.py`, `new.py` and `install.py`. Keep zero
external dependencies.

Implementation details:
- **Explicit paths instead of module globals**: functions take a `root: Path` argument
  (e.g. `update_board(root)`), removing the need for `patch.object` in tests.
- **pathlib** instead of `os.path` (`read_text(encoding="utf-8")`, `glob("*.md")`).
- **argparse** for all CLIs (`--help`, `--version`, proper usage errors).
- **Data model**: `@dataclass(frozen=True) class Ticket`.
- **Separation of concerns**: `load_tickets()` → `build_tree()` → `render_board() -> str`
  (pure) → `write_board()`.
- **Error handling**: raise exceptions in library code; `main()` catches, prints to stderr and
  returns an exit code. No `sys.exit()` deep in helpers (e.g. `fetch_remote_file`).
- **Atomic writes** for `BOARD.md` and tickets (temp file + `os.replace`).
- **Remove `sys.path.append` hack** in `new.py`.
- **Type hints and docstrings** for all public functions; module docstrings.

Acceptance criteria:
