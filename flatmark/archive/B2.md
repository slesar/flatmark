# Frontmatter without trailing newline is ignored

The frontmatter regex in `board.py` (`^---\s*\n(.*?)\n---\s*\n`) requires a newline after the
closing `---`. A ticket file that ends right after the closing delimiter (common when agents
write files without a final newline) is parsed as having no frontmatter and is **silently
skipped**.

Acceptance criteria:
- [x] Closing `---` followed by end-of-file is accepted (e.g. `\n---\s*(\n|$)`).
- [x] CRLF line endings are supported.
- [x] Files in `tickets/` with missing/invalid frontmatter produce a stderr warning instead of
      being silently dropped.
- [x] Regression tests for both cases.
