# Pipe character in title breaks board table

Ticket titles and frontmatter values are written into the Markdown table without escaping.
A `|` in a title (e.g. `# Parse A | B`) splits the cell and corrupts the row.

Acceptance criteria:
- [x] All values rendered into table cells escape `|` as `\|`.
- [x] Newlines/leading/trailing whitespace in values are normalized.
- [x] Regression test with a pipe in the title and in the status.
