# Unified flatmark CLI with agent-friendly verbs

Agents perform better with deterministic commands than with "edit YAML, then move file, then
regenerate". Consolidate scripts into a single `flatmark.py` entry point (keep `board.py` and
`new.py` as thin wrappers for backward compatibility).

Commands:
- `new <type> <title> [--parent ID] [--blocked-by ID] [--priority P]`
- `start <id>` — set `In Progress`
- `done <id>` / `obsolete <id>` — set status and move to `archive/` in one step
- `board [--check]`
- `list [--status S] [--priority P] [--json]` — query backlog without parsing Markdown
- `next [--json]` — highest-priority unblocked `Todo` ticket
- `show <id> [--json]`

Acceptance criteria:
- [x] All commands implemented; every mutating command regenerates the board.
- [x] `--json` output schema documented in `AGENTS.md`.
- [x] `AGENTS.md` updated to prefer CLI verbs over manual edits.
- [x] Tests for each command.
